Accessible in use

  

    
    
      
  1. Checks first. A keyboard-only test and an axe scan, written before you prompt. Commit them failing.
    2. 
      
  2. Build it twice. Plain agent vs agent + an accessibility skill. Count the failures. Is the skill worth it?
    3. 
      
  3. Let an agent use it. Give an agent browser tools and a task. Then turn one button into a div. Again.
    4. 
      
  4. By hand, no AI. Keyboard only, a screen reader, 200% zoom. What did the tests miss?

// keyboard.spec.ts · written before the page exists
test('keyboard only: search and save', async ({ page }) => {
  await page.goto('/');
  await page.keyboard.press('Tab');
  await expect(page.getByRole('searchbox')).toBeFocused();
  await page.keyboard.type('Hekla');
  await page.keyboard.press('Enter');
  await page.keyboard.press('Tab');
  await expect(page.getByRole('button', { name: 'Save' }))
    .toBeFocused();});

test('no serious axe violations', async ({ page }) => {
  await page.goto('/');
  const { violations } = await new AxeBuilder({ page }).analyze();
  expect(violations.filter(v => v.impact === 'critical'
    || v.impact === 'serious')).toEqual([]);
});

description: Use when building or changing any UI
  in this repo. Lists our components, our tokens and

# Our design system
- Buttons: <Button variant="primary|secondary">.
  Never a styled div.
- Colours: only tokens from tokens.css. No hex
  values inside components.
- Spacing: --space-1 to --space-6.
- Before adding a component, look in
  src/components/. It probably exists.
- Every icon-only button gets a name.

From our style library

  
What no model knew

  

    
FontsPress Start 2P breaks Icelandic accented capitals. Use it for Latin text and digits only.

    
Pixel gridsJersey 15 is readable at exactly 22 px (or 44, 66). At 15–20 px its R turns into an A.

    
VoicesThe Tiro service stopped responding. Gunnar (Edge neural) is the Icelandic voice that works.

    
Render costWatercolour: seconds per frame, the laptop gets hot. Arcade: 80 s renders in 1.5 min.

    
Test wordsCheck GERVIGREIND, KÓÐANN, ÞÚ, ÆÐI in any font before you build anything.

Every guide

  
Six rules

  

    
1Checks before promptsWrite the test or the acceptance check first. Small diffs, git every step.

    
2Ask, then interrogateNever accept a whole task unread. Ask why, ask what else, ask what breaks.

    
3AI off, once a weekA short debugging session by hand. The 4.5 check is the graded version.

    
4Defend it out loudWeekly, 10–15 min: walk someone through a random part of your own code.

    
5When the agent is stuckReset the context · smaller step · a failing test · read the error yourself · git reset.

    
6What the AI got wrongA section in every report, as in Module 3. Plus the prompts that mattered.
